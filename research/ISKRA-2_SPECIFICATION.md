## 1. Видение Iskra-2 (одним абзацем)

Iskra-2 превращает Iskra-1 из «системы, которая иногда думает сама» в **систему с настоящей долговременной памятью и agency**.  
Модель получает возможность:
- хранить опыт между всеми сессиями,
- сама решать, что сохранять / обновлять / забывать,
- активно управлять своей памятью (в пределах заданных уровней прав),
- использовать накопленную память для формирования спонтанных мыслей и поведения.

Это первый реальный шаг к **Persistent Agency** — модели, которая существует даже когда её никто не спрашивает.

## 2. Ключевые отличия от Iskra-1

| Аспект                  | Iskra-1 (текущая)                  | Iskra-2 (цель)                                      |
|-------------------------|------------------------------------|-----------------------------------------------------|
| Память                  | Эфемерная, с decay                 | Постоянная, векторно-графовая, манипулируемая      |
| Agency                  | Только спонтанные мысли            | + возможность активно управлять своей памятью       |
| Уровень прав модели     | Только чтение + косвенное влияние  | Level 0 → Level 3 (Suggest → Full control)         |
| Эмоциональный слой      | Только 3 переменные                | + emotional_valence, arousal, self-reflection       |
| Основной режим          | Спонтанность по таймеру            | Спонтанность + активные запросы к памяти            |

## 3. Цели Iskra-2 (MVP)

К концу Iskra-2 модель должна уметь:

1. **Persistent Memory**
   - Хранить воспоминания между перезапусками демона и между разными чат-сессиями.
   - Искать по смыслу (векторный поиск).
   - Иметь граф связей (ассоциации).

2. **Manipulable Memory**
   - Читать память (пассивно и по запросу).
   - Предлагать сохранение / обновление / удаление (Level 1).
   - Получать право напрямую сохранять и обновлять записи (Level 2–3 по конфигу).

3. **Новые теги общения**
   - `[MEMORY_REQUEST] ...` — попросить воспоминания.
   - `[MEMORY_UPDATE] ...` — изменить важность / добавить связи.
   - `[INTERNAL_THOUGHT]` — обычная спонтанная мысль (сохраняется из Iskra-1).

4. **Улучшенный State Engine**
   - Добавить `emotional_valence` и `arousal`.
   - Self-reflection (модель может критиковать свои прошлые мысли).

## 4. Архитектурные изменения (что именно меняем/добавляем)

- **Memory Store** → заменяется на новый гибридный (LanceDB + NetworkX или ArangoDB).
- **Intent Generator** → расширяется поддержкой новых тегов `[MEMORY_*]`.
- **State Engine** → добавляются 2 новые переменные + self-reflection loop.
- **Trigger Engine** → добавляются триггеры, связанные с памятью.
- **MainLoop** → добавляется обработка специальных тегов от модели.
- **Config** → добавляется секция `memory.v2` и `agency.level`.

Старый код Iskra-1 остаётся полностью рабочим (режим `version: 1`).

## 5. Поэтапный план разработки Iskra-2

**Этап 2.1 (MVP Iskra-2) — 4–6 недель**
- Новый Memory Store (LanceDB + простой граф)
- Поддержка тегов `[MEMORY_REQUEST]` и `[MEMORY_UPDATE]`
- Level 1 (Suggest) прав
- Миграция существующих воспоминаний из Iskra-1
- Тестирование на твоём универсальном чат-боте

**Этап 2.2 — 4 недели**
- Level 2–3 прав
- Emotional_valence + arousal
- Автоматическая консолидация памяти (раз в сутки)

**Этап 2.3 — полировка**
- Графовые ассоциации
- Self-reflection loop
- Полная совместимость с Iskra-1
