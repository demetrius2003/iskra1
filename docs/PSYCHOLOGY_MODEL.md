# Модель интенции: от улитки к человеку

## Зачем этот документ

Описывает **биологический образец**, на который ориентируется Iskra-1. Мы не моделируем человеческий мозг — мы моделируем **минимальный организм, обладающий спонтанной интенцией**, и закладываем путь масштабирования к произвольной сложности.

## Уровни сложности интенции (лестница эволюции)

### Уровень 0 — Бактерия (~0 нейронов)
- Нет памяти, нет состояния.
- Реагирует на градиент химических веществ (хемотаксис).
- **Для Iskra-1:** аналог — cron-задача, которая шлёт рандомный промпт. Это не интенция. Это **ниже** нашего порога.

### Уровень 1 — Улитка (~10 000 нейронов) ← **стартовая точка Iskra-1**
- Есть внутреннее состояние (голод, страх, покой).
- Есть примитивная память (ассоциация «место → еда»).
- Есть спонтанное поведение, не объяснимое только внешними стимулами.
- Поведение **стохастическое**: в одинаковых условиях может поступить по-разному.
- **Для Iskra-1:** минимальное ядро с 3 переменными состояния + простая память + стохастический триггер.

### Уровень 2 — Кот (~250 000 000 нейронов)
- Богатое эмоциональное состояние.
- Эпизодическая память (помнит конкретные события).
- Сложные ритуалы поведения («прошивка», как описал автор проекта).
- Спонтанная интенция с переключением контекста: лежал → бах → помчался.
- **Для Iskra-1 (будущее):** десятки переменных состояния, сложная память с ассоциативным поиском, циклы сна/бодрствования.

### Уровень 3 — Человек (~86 000 000 000 нейронов)
- Непрерывный внутренний монолог.
- «Машина память» (Маша-память) — долговременные якоря, всплывающие спонтанно через дни/месяцы/годы.
- Короткая рабочая память (2000–3000 «строк кода» одновременно).
- Иррациональные переключения контекста: пишешь код → бах → стихи про Машу.
- **Для Iskra-1 (далёкое будущее):** полноценная система с эмоциональным двигателем, сенсорными входами, социальной моделью, рефлексией.

## Что общего у всех уровней

Каждый уровень выше нуля обладает тремя минимальными свойствами:

1. **Внутреннее состояние** — хотя бы одна переменная, которая меняется без внешнего воздействия.
2. **Стохастичность** — в одинаковых условиях система может поступить по-разному.
3. **Влияние прошлого на настоящее** — хотя бы простейшая память.

Именно эти три свойства отличают «организм с интенцией» от «программы, выполняющей инструкции».

## Принцип масштабирования

Переход между уровнями — это **добавление**, а не замена:
- Добавляем новые переменные состояния (не переписываем старые).
- Добавляем новые типы памяти (не ломаем существующие).
- Добавляем новые типы триггеров (не удаляем базовые).

Фреймворк растёт **как живой организм**: наращивает сложность, сохраняя работающее ядро.
